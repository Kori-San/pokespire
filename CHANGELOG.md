## [Unreleased]

### Added

- **Scaffold + PWA + i18n**
  - Vite + React 18 + TypeScript project with strict tsconfig.
  - Tooling: ESLint (flat config, type-checked), Prettier, Vitest + Testing Library, Husky + lint-staged (pre-commit runs format + lint + the full test suite).
  - Self-hosted OFL fonts (Press Start 2P, Pixelify Sans) and design tokens (`tokens.css`) preserving the prototype PAL palette plus all 18 Pokémon type colors.
  - PWA via `vite-plugin-pwa`: web manifest, auto-update service worker, runtime caching for PokéAPI + sprite origins.
  - Internationalization via `react-i18next` with French and English locales, surfaced as a globe button opening a flag dropdown (UK / France).
  - TitleScreen with GBA-era chrome and a New Game button.
  - Documentation: `rules/` (technical standards), `wiki/` (game design), numbered `planning/` plans, and `CLAUDE.md` (agent working agreement).
- **Developer tooling**
  - Storybook 10 (React + Vite) with a11y addon and stories for the UI primitives; PWA disabled under Storybook so it builds cleanly.
  - Hardened ESLint to `strict-type-checked` + `stylistic-type-checked`, with the Storybook and Vitest plugins; added a `cx` class-name helper.
  - Autoprefixer + a generous browserslist (`last 2 years`, `> 0.5%`, Firefox ESR, not dead).
  - Pre-commit now also runs a `tsc` typecheck (lint-staged → typecheck → tests).
  - `npm run dev:all` runs the app and Storybook together (via `concurrently`).
  - GitHub Actions CI (typecheck/lint, tests + coverage, build) and Dependabot (npm + github-actions, grouped minor/patch, ⬆️ gitmoji prefix).
  - commitlint with a gitmoji rule (`commit-msg` hook) enforcing our `<gitmoji> <subject>` style.
  - Vitest v8 coverage (`npm run test:coverage`, report-only) and a `knip` script for unused-code detection.
  - `eslint-plugin-i18next` flags hardcoded user-facing JSX text in app code.
  - Claude Code permission guardrails (`.claude/settings.json`): plan-mode default, deny push/force/reset/clean/secret reads; a sectioned `.gitignore`.
- **Combat vertical slice** (in progress)
  - Shared domain types: `PokeType` (18 types), base stats, growth rates, statuses, card/effect shapes, and combat state/actions.
  - 18×18 modern type chart with combined dual-type effectiveness (`typeEffectiveness`).
  - Deterministic damage formula (`calcDamage`): STAB, type effectiveness with a chip floor for immunities, level + base-stat scaling, plus WEAK / weather / held-item hooks. Returns a full breakdown for the live card display; covered by worked-example tests.
  - Capture math (`calcCaptureChance` / `rollCapture`) using the real Gen III/IV formula: a small catch chance even at full HP that rises as HP drops, real ball tiers (Poké/Great/Ultra/Master), a shiny ×5 bonus, and an injected RNG for determinism.
  - Status registry (BURN, WEAK) with `applyStatus` and an end-of-turn `tickStatuses` (tick damage then per-stack decay).
  - Deck helpers (seeded shuffle + draw with discard reshuffle), data-driven effect executor (`applyEffect`), and a ~18-card starter pool (incl. weather + ball cards).
  - Enemy intent AI, a seeded resumable RNG (`rngFrom`), and the pure combat reducer (`createCombat` + PLAY_CARD / SWITCH / END_TURN with enemy phase, status ticks, faints, next-turn draw).
  - `ASSETS.md` asset-tracking registry — every committed binary asset gets a row with source URL, license, and refresh command; updated in the same commit that adds the asset.
  - `HpBar` primitive — banded fill colors (high / mid / low) over a GBA-tinted track, with Storybook stories at each tier.
  - `TypeChip` primitive — small 18-type tinted chip for surfacing a Pokémon's typing, with one story per type.
  - `EnergyPip` + `EnergyBar` primitives — GBA-flavored slanted bars in a `current`-out-of-`max` row. Used by hand cards (cost) and the combat HUD (remaining energy this turn).
  - Missingno fallback sprite (`public/sprites/fallback/missingno.gif`), replacing the placeholder `unknown.png`. Credit: RetroNC on DeviantArt.
  - Local sprite resolver (`spriteUrl`, keyed by `formId`, Missingno fallback when the species has no vendored animated sprite).
  - **Move-category vendoring pipeline:** `scripts/fetch-move-icons.mjs` (`npm run fetch-move-icons`) downloads the HGSS physical / special / status icons from Bulbapedia (`Special:FilePath` redirect, hash-stable) into `public/sprites/move-category/`. Three 32×14 PNGs, served locally.
  - Live-i18n hand card: `selectCardLines` returns structured `EffectLine[]` descriptors with no strings; `Card.tsx` translates each line via `useTranslation` so "Deal X damage." pulls from `card.lines.*` in FR/EN and substitutes the **live computed** value. CardDef carries no static `text`; description is generated from `effects` + the view. Storybook stories include a Playground (flat controls for prototyping new cards) and a Gallery (all CARDS at a glance).
  - CardDef gains a canonical `category: 'physical' | 'special' | 'status'` field — the Gen-IV move split that selects atk/def vs spAtk/spDef in the damage formula. The HGSS icon vendored above renders on the card footer; ATK/SKL/PWR/BALL kind text dropped in favor of the iconic indicator.

### Changed

- **Locales split into namespaces** so the card pool can grow without bloating a single JSON: `ui` (default — title / common), `cards` (effect-line templates / kinds / statuses / weather), `cardNames` (one entry per card; the only file that grows with content). Files now live under `src/locales/<lang>/{ui,cards,cardNames}.json`. Call-site keys: `t('title.newGame')`, `t('cards:lines.damage')`, `t('cardNames:tackle')`.
- **CardKind gains `ITEM`** for non-canonical consumables (Potion, X Attack, Repel, …). BALL and ITEM cards now use their own border colors — `--card-ball` (Poké Ball red) and `--card-item` (potion amber) — sitting outside the 18-type palette so they read as their own category at a glance. Type-flavored kinds (ATK / SKL / PWR) still inherit `--type-${type}`.
- **Cards-data split into per-type files** under `src/data/cards/` — one file per Pokémon type that has cards (`normal.ts`, `fire.ts`, `water.ts`, …), plus `balls.ts` (BALL kind) and `items.ts` (ITEM kind). `cards/index.ts` merges them into the `CARDS` Record and exports `STARTER_DECK`. Balancing one type's pool = open one file.
- **Physical / special damage split** in `damage.ts` — `DamageParams.category` selects which stat pair the formula reads. `physical` → `attacker.atk` / `defender.def`; `special` → `attacker.spAtk` / `defender.spDef`. Drafting a Special card into a physically-bulky mon now lands harder than the Physical alternative (and vice versa), as in canonical Gen-IV+.
- **`Rarity` on CardDef** (`common` / `uncommon` / `rare` / `epic`), tied to canonical move PP — drives reward-table offer rates and shop drafts. Every existing card has been tagged; e.g. Recover, Sunny Day, Rain Dance are `epic` (5 PP), Ember and Water Gun are `uncommon` (25 PP), Tackle and Quick Attack are `common`. Storybook Playground exposes a rarity control.
- **Stat-stage system** — Combatants gain `stages: StatStages` (atk/def/spAtk/spDef/spd + a Pokespire-only `crit` stage; accuracy/evasion intentionally absent since cards always land). New `stat` Effect kind (`{ target, stat, stages }`) raises or lowers stages, clamped to ±6. The damage formula reads stage-multiplied stats through canonical Gen-III stage table. Stages reset on switch-out (per canon) and at combat end (combat state is per-battle). Crit-rate stages drive a crit roll in `applyEffect` for damage; on a crit, damage is ×1.5 and the player sees the bigger number. Added SWORDS DANCE card (normal, rare, self +2 atk) as the first stat-stage consumer. Locales now carry `stat.*` names and 4 `lines.stat*` templates.
- **Speed turn-order** — at the start of each turn (and on combat start), if `effectiveSpeed(enemy) > effectiveSpeed(activeMon)` the enemy executes its telegraphed intent **before** the player can play any cards, then `state.enemyActed = true` so the end-of-turn flow skips the enemy phase (enemy still acts exactly once per turn). Ties favor the player. Switching does NOT grant the enemy a free strike — the 1-energy cost is already the brake (see wiki/combat-formula.md). Drafting Agility / Dragon Dance (future cards) is now a real positional lever.
- **Card pool expanded ~18 → ~82** to exercise every new mechanic — physical/special, stat-stage buffs and debuffs, crit-stage boosters, weather, BALL tier ramp, healing items. All 18 Pokémon types now have files: heavy hitters (Hyper Beam, Earthquake, Stone Edge), set-up moves (Calm Mind, Bulk Up, Dragon Dance, Quiver Dance, Shell Smash), debuff-on-damage (Crunch, Moonblast, Play Rough, Bug Buzz, Earth Power, Shadow Ball, Flash Cannon, Energy Ball), crit-boosters (Shadow Claw, Night Slash, Stone Edge), drain-flavor (Draining Kiss), and weather-setters (Sunny Day, Rain Dance, Sandstorm, Snowscape). Full ball line (Poké / Great / Ultra / Master) with `master` guaranteeing the catch. Item kind cards: 4 potion tiers (15 / 30 / 60 / full-restore), X Attack / X Defend / X Speed (+1 stage), Dire Hit (+2 crit). FR locale carries canonical move names where they map cleanly. Gallery story renders the whole pool unchanged — every card shows up.
- **`lifesteal` Effect kind** — damage + percent-of-damage heal in a single atomic effect. The full damage formula runs (STAB / type-eff / stat-stages / crit roll), then the attacker heals `percent`% of the dealt amount; both the displayed damage AND heal scale with every multiplier together. Card text reads `Deal X damage, recover Y HP.` and both numbers update live for the current matchup. Five lifesteal cards land: Draining Kiss (fairy, 75%), Giga Drain (grass, 50%), Drain Punch (fighting, 50%), Leech Life (bug, 50%), Parabolic Charge (electric, 50%). Storybook Playground exposes a `lifestealPercent` control.
  - **Pokédex vendoring pipeline:** `scripts/fetch-pokedex.mjs` (`npm run fetch-pokedex`) downloads Gen 1 data + BW-animated sprites locally so we self-host them (no runtime PokéAPI). All-gens, multi-form schema — per-form types/stats/sprites keyed by `formId`, plus generation, growth/catch rate, gender data, evolution links, and legendary/mythical/mega/Gmax + solo-only flags. Modes: `--dry-run`, `--skip-existing`, `--only`.
- **Terastallization — 18 Tera Crystal cards, one per Pokémon type.** Cost-2 SKL, rare (chosen over epic so 18 distinct cards still drop at a healthy cadence), `exhaust: true` (once per battle). Generated programmatically from `POKE_TYPES` in `data/cards/teraCrystals.ts`. Playing a Tera card locks the active mon's `tera.type` for the rest of combat — no revert, the mon's effective type for STAB becomes the Tera type. New `terastallizeCombatant` helper + `{ kind: 'terastallize'; teraType: PokeType }` Effect. Damage formula updated with the canon **Tera Boost** rule: if a card's type matches BOTH the Tera type AND one of the mon's original types, STAB stacks to ×2 instead of ×1.5; if the card's type matches an original type but NOT the Tera type, STAB drops to ×1 (the mon counts as only its Tera type post-cristal). Affordability gated on `!attacker.tera`. New `tera` keyword chip uses the canon Cobblemon-derived `/sprites/misc/tera.png` mark. New `theme: 'tera'` paints a crystalline conic border keyed off `--card-type` (so Tera Fire = orange gem, Tera Water = blue gem, …) with light + mid + deep stops mixed via `color-mix` to suggest cut-gem facets, plus a soft outer glow and a twinkle (brightness pulse instead of hue-rotate so each card's type identity stays readable). FR locale uses canon names (Téra Feu, Téra Eau, Téra Électrik, Téra Plante, Téra Glace, Téra Combat, Téra Poison, Téra Sol, Téra Vol, Téra Psy, Téra Insecte, Téra Roche, Téra Spectre, Téra Dragon, Téra Ténèbres, Téra Acier, Téra Fée, Téra Normal). Keyword desc explicitly references STAB so the player connects the two mechanics. 114 tests passing — STAB / Tera-Boost / STAB-loss / no-Tera-baseline all covered.
- **Inventory layer — Phase 2 of the redesign.** `CardKind` narrowed to `'ATK' | 'SKL' | 'PWR'` (drops `'BALL'` + `'ITEM'`); the matching `balls.ts` + `items.ts` card files, their locales (cardNames + `kind.BALL`/`kind.ITEM`), starter-deck `pokeBall` seed, and the `--card-ball` / `--card-item` palette tokens all go away. New `src/types/run.ts` carries an `Inventory` shape — `balls` (4 tiers), `potions` (4 tiers), `xItems` (atk/def/spd/hit), `berries` (sitrus/lum/chesto/liechi), `gold` — plus a `freshInventory()` factory (Day-0: 5 Poké Balls, 2 standard Potions, 50 gold). The `capture` and `heal` `Effect` kinds stay in the union: capture will be invoked by the post-battle prompt (Phase 6), heal is still used by canonical healing moves. `exhaustsOnPlay()` now reads `card.exhaust` only (the kind-based BALL/ITEM routing went with the redesign). 108 tests passing — the BALL/ITEM-exhaust and capture-percent test cases get replaced by an inventory-bound starter-deck guard and a small `freshInventory()` test.
- **Mega Evolve + Dynamax meta-mechanic cards** — two epic-tier `data/cards/special.ts` cards (cost 2 SKL, exhaust on play, theme-overridden visuals) sitting outside the 18-type palette so future Normal-boosting relics don't catch them. Mega Evolve looks up the active mon's first canonical Mega forme (rainbow conic border + hue-rotate shimmer); affordability greys the card out for species without one. Dynamax doubles `maxHp` for 3 turns (heals the gained capacity, ticks down in `endTurn`, reverts + clamps hp on expiry), swaps to the species' Gmax forme when one exists, and remaps the active mon's hand to canon Max Moves (18 typed entries — Pyromax, Hydromax, Fulguromax, Phytomax, Cryomax, Pugilomax, Toxinomax, Sismomax, Aéromax, Psychomax, Insectomax, Lithomax, Spectromax, Dracomax, Sinistromax, Métallomax, Enchantomax, Normalomax — plus a universal Garde Max for SKL/PWR). Charizard, Pikachu, Snorlax, Gengar, and Corviknight have signature G-Max moves (Fournaise / Foudre / Récolte / Hantise / Rafale G-Max) that replace same-type ATKs. Each Max Move carries its canon secondary effect: weather (Fire/Water/Rock/Ice), terrain (Electric/Grass/Fairy/Psychic), self-stat bump (Fighting/Poison/Flying), column ally bump (Ground/Steel), or foe-stat lower (Normal/Bug/Ghost/Dragon/Dark). `KEYWORD_VISUAL` extended to accept PNG-image entries (Showdown's `misc/mega.png` and Cobblemon-derived `dmax.png`); new `KwIcon` component centralises img-vs-Iconify rendering with `height: auto` so non-square marks keep their aspect ratio. Keyword chip order restructured: card-defining mechanics (megaEvolve / dynamax) lead, matchup chips next, effect riders middle, meta tags (exhaust / ephemeral) trail. Boss-tier `megaEvolve` / `dynamax` enemy Intents wired through `enemyAct` via shared `megaEvolveCombatant` / `dynamaxCombatant` helpers; IntentBadge renders them with the canon marks and themed top stripes (StS-style arrow nub preserved). Localised FR + EN with canon pokepedia translations. Per-card `exhaust?: boolean` flag added so ATK / SKL / PWR cards can opt into per-combat exhaust without misrepresenting their kind.
